# SectionHeader

Rótulo numerado en mono `accent` sobre un H2 serif; abre cada sección.

- `p.az-eyebrow` ("01 / Trabajo") + `h2.az-h2` ("Trabajo seleccionado"). El número sigue el orden de la sección en la página.
- El H2 nunca lleva cursiva ni color: el énfasis queda para el hero y el cierre.
- La sección va en `section.az-wrap.az-section` con un `id` igual al ancla de la navegación.
