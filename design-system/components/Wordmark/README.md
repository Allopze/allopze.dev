# Wordmark

La marca es la palabra "allopze" en Newsreader cursiva, minúsculas, color `ink`; no existe logo gráfico.

- Clase `az-wordmark` sobre un `<a href="/">`. Alto mínimo 44px.
- Nunca en mayúsculas, nunca en `accent`, nunca con un ícono al lado.
- En prosa el nombre se escribe "Allopze" (con mayúscula), como en "Hecho por Allopze".
