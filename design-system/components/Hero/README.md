# Hero

Apertura de la página: rótulo, H1 serif con cierre en cursiva `accent`, bajada y dos botones, con el campo de líneas al costado.

- `section.az-wrap.az-hero > div.az-hero__text + div.az-hero__art`. El texto toma el lado ancho (`flex: 999 1 600px`), el campo de líneas el angosto (`flex: 1 1 340px`, máx. 520px).
- Rótulo `az-eyebrow`, H1 `az-h1` con `<em class="az-em">` en las palabras finales, bajada `az-lead`, botones en `az-actions` (primario + ghost).
- En móvil el campo de líneas baja debajo del texto.
- Un solo H1 por página.
