# ContactBlock

Cierre de la página: una pregunta enorme en serif con "Escríbeme." en cursiva `accent`, y dos botones.

- `section.az-wrap.az-contact#contacto > h2.az-display-xl > em.az-em` + `div.az-actions`.
- Primario: "Escribir por correo →" (`mailto:`). Secundario: "WhatsApp →" (`https://wa.me/<número>` con mensaje prellenado).
- Es el único lugar con `display-xl`. Sin formulario: el contacto es directo.
