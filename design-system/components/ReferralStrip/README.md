# ReferralStrip

Franja de una línea bajo el hero que le habla a quien llegó desde el footer "Hecho por Allopze" de un sitio cliente.

- Entre dos hairlines `line`. Marca ↳ en mono `accent`, texto en `ink`, enlace mono a la derecha ("Ver otros trabajos →").
- Texto por defecto: "¿Llegaste desde el sitio de un cliente? Ese sitio también lo hice yo."
- Con `?desde=<slug>` en la URL y un slug conocido, el texto nombra el sitio: "Llegaste desde el sitio de Chome LTDA. Ese sitio también lo hice yo." Solo slugs de una lista fija; el valor de la URL nunca se escribe en la página.
